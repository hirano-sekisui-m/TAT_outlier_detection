# 機械学習用データセット構築スクリプト 取扱説明書

本ドキュメントでは、生測定CSVデータから統合データをエクスポートし、機械学習用の特徴量データセット（Excel）を自動生成する一連のスクリプトの使用方法および仕様について解説します。

---

## 1. 全体概要とワークフロー

データセット作成パイプラインは以下の2段階で構成されています。

```
[生CSVデータ (単一または複数)]
         │
         ▼ (1) 統合エクスポート用Pythonスクリプト.py
[統合データフォルダ (measurement.parquet, profile.parquet, metadata.json)]
         │
         ▼ (2) build_ml_dataset.py
[最終機械学習用データセット (機械学習用データセット.xlsx)]
```

---

## 2. 統合エクスポートスクリプト (`統合エクスポート用Pythonスクリプト.py`)

### 2.1 概要
複数の生測定CSV（F07装置出力）を個別にパースし、項目列の相違や依頼No.の重複を調整して、一貫した統合データセット (`measurement.parquet`, `profile.parquet`, `metadata.json`) を出力します。

### 2.2 入力ファイルの要件
- **ファイル形式**: CSV形式（F07生データ仕様）
- **文字コード**: `cp932` (Shift-JIS), `utf-8-sig`, `utf-8` を自動試行
- **ヌルバイト対策**: 装置生CSVに含まれる場合があるヌルバイト (`\x00`) を自動クレンジングして全行読み込みます。
- **データ件数**: 1ファイルだけでも、複数ファイルでも同一のフォーマットで出力されます。

### 2.3 入出力パスの設定（スクリプト内設定エリア）
スクリプトを開いて **50行目付近** にある設定エリアでデフォルトパスを変更できます。

```python
# ==========================================================
# 設定エリア (パスを変更したい場合はここを書き換えてください)
# ==========================================================
PROJECT_ROOT = Path(__file__).resolve().parent.parent.parent

# 入力生CSVが含まれるフォルダパス
DEFAULT_INPUT_DIR = PROJECT_ROOT / "data" / "example" / "複数csvの例"

# 統合データ (measurement.parquet, profile.parquet等) の出力先フォルダパス
DEFAULT_OUTPUT_DIR = PROJECT_ROOT / "data" / "example" / "integrated_export"
# ==========================================================
```

### 2.4 主な機能と特徴
- **一意の識別子追加**: ファイル毎に `source_index`, `source_file`, `global_request_id` (`ファイル番号_依頼No.`) を付与し、依頼No.重複を回避。
- **柔軟なパース**: 測定テーブルと時間変化吸光度プロファイル（Profile）を自動分解。
- **複数形式で出力**: 高速な `Parquet` 形式と、確認用の `CSV` / `JSON` を同時にエクスポート。

### 2.5 実行方法
```bash
# 引数なしで実行（設定エリアで指定したパスを使用）
python scripts/data-manage/統合エクスポート用Pythonスクリプト.py

# オプション引数を渡して任意のフォルダを指定して実行することも可能
python scripts/data-manage/統合エクスポート用Pythonスクリプト.py --input-dir "data/raw" --output-dir "data/interim/export"
```

## 3. 機械学習データセット構築スクリプト (`build_ml_dataset.py`)

### 3.1 概要
統合済みデータ (`measurement.parquet`, `profile.parquet`) を読み込み、キャリブレーションカーブに基づく 7 つの測光ポイントパターン濃度および各種統計特徴量を算出、目標Excelフォーマットに準拠した `機械学習用データセット.xlsx` を生成します。

### 3.2 入力ファイルの要件
- 統合エクスポートスクリプトが出力した `measurement.parquet` (または `measurement.csv`) および `profile.parquet` (または `profile.csv`) が配置されているフォルダ。

### 3.3 入出力パスの設定（スクリプト内設定エリア）
スクリプトを開いて **25行目付近** にある設定エリアでデフォルトパスを変更できます。

```python
# ==========================================================
# 設定エリア (パスを変更したい場合はここを書き換えてください)
# ==========================================================
# 入力ディレクトリ: measurement.parquet や profile.parquet が入っているフォルダ
DEFAULT_INPUT_DIR = BASE_DIR / "data" / "example" / "integrated_export"

# 出力Excelファイル: 機械学習用データセットの保存先
DEFAULT_OUTPUT_EXCEL = BASE_DIR / "data" / "example" / "機械学習用データセット.xlsx"
# ==========================================================
```

### 3.4 主な機能と特徴
- **濃度再計算ロジックの適用**:
  - `2-8`, `4-10`, `6-12`, `8-14`, `10-16`, `12-18`, `14-20` の各測光ポイント範囲における吸光度変化率 (Rate) を算出。
  - Calibrator (C001, C002...) および属性表記から検量線 (Calibration Curve) を自動構築し、区分線形補間・補外処理により各ポイントの換算濃度を計算。
- **特徴量エンジニアリング**:
  - `平均`, `最大`, `最小`, `レンジ`, `最大上昇率`, `最大上昇速度`, `最大下落率`, `最大下落速度`
  - 相対変化率: `4-10/2-8`, `6-12/2-8`, `8-14/2-8`, `10-16/2-8`, `12-18/2-8`, `14-20/2-8`
- **厳密なカラム並び順**: 全29列の項目名と並び順が仕様に100%合致したExcelファイルを作成。

### 3.5 実行方法
```bash
# 引数なしで実行（設定エリアで指定したパスを使用）
python scripts/data-manage/build_ml_dataset.py

# オプション引数を渡して実行する場合
python scripts/data-manage/build_ml_dataset.py --input-dir "data/example/integrated_export" --output-excel "data/processed/ml_dataset.xlsx"
```

## 4. 注意点・トラブルシューティング

1. **生CSV読み込み時のヌルバイトエラー**:
   - `統合エクスポート用Pythonスクリプト.py` 内でヌルバイト `\x00` の除去を自動で行います。他のツールでパースエラーが出る場合も本スクリプトを通すことで正常化されます。
2. **入出力ディレクトリの作成**:
   - 出力先ディレクトリが存在しない場合、スクリプトが自動的にディレクトリを作成します。
3. **Parquet形式の利点**:
   - データ量が多い場合、CSVに比べてParquet形式は読み込み速度が大幅に高速化されます。
