# 未知データ検証・予測スクリプト 取扱説明書

本ドキュメントでは、学習済みモデル（`.joblib`）を読み込み、新しい未知の測定データセット（ExcelまたはCSV）に対して分類（予測クラス・予測確率）や回帰（予測数値）の推論を一括実行し、予測結果レポートを出力する `scripts/validate/predict_ml_models.py` の使用方法および仕様について解説します。

---

## 1. 全体概要

`scripts/validate/predict_ml_models.py` は、構築された機械学習モデルを実運用環境や新規実験データに適用するための推論・検証用スクリプトです。

- **分類モデルの場合**: 各検体サンプルに対する**予測クラス (0/1)** および **陽性予測確率 (0.0〜1.0)** を算出します。
- **回帰モデルの場合**: 各検体サンプルに対する **連続予測値** を算出します。

入力された未知データの特徴量カラムを自動検証し、欠損行を安全にスキップした上で、結果を見やすいExcelレポートとしてエクスポートします。

---

## 2. 入力・出力ファイルの仕様

### 2.1 入力ファイルの要件
1. **学習済みモデルファイル (`.joblib`)**:
   - `train_ml_models.py` または `build_high_rf.py` 等で保存された `.joblib` 形式のモデルファイル。
   - モデル本体とともに、学習時に使用した特徴量リスト (`feature_cols`) やタスク種別 (`task_type`) などのメタデータが含まれています。
2. **未知データセットファイル (`.xlsx` または `.csv`)**:
   - `build_ml_dataset.py` で出力された `機械学習用データセット.xlsx` または同等の列構成を持つ新規測定データ。
   - 学習時と同じ 22 種の特徴量（`2-8` 〜 `14-20`, `平均`, `最大`, `最小`, `レンジ`, `最大上昇率`, `最大上昇速度`, `最大下落率`, `最大下落速度`, `4-10/2-8` 〜 `14-20/2-8` 等）が含まれている必要があります。

### 2.2 出力ファイルのパス
デフォルトの出力ディレクトリ:
- **予測結果エクスポート先**: `reports/validation/prediction_results.xlsx`

#### 生成される成果物 (Excel シート構成):
1. **`Predictions` シート**:
   - サンプル識別列（`source_index`, `source_file`, `global_request_id`, `依頼No.`, `SID`, `属性`, `SampleType`）
   - **分類の場合**: `predicted_probability` (予測確率), `predicted_class` (予測クラス 0/1)
   - **回帰の場合**: `predicted_value` (予測数値)
2. **`Run_Info` シート**:
   - 推論実行日時、使用モデル名、タスク種別、正解ラベルの定義内容、読み込んだモデルファイルパス、入力データ件数、推論成功件数などの実行メタデータ。

## 3. スクリプトの書き換え・カスタマイズ方法（設定エリア）

スクリプト `scripts/validate/predict_ml_models.py` を開いて **25〜35行目付近** にある設定エリアを書き換えることで、使用するモデルや入力ファイルを簡単に切り替えられます。

```python
# ==========================================================
# 設定エリア (パスを変更したい場合はここを書き換えてください)
# ==========================================================

# 1. 検証・予測対象の未知データセット (Excel / CSV)
DEFAULT_INPUT_DATASET = PROJECT_ROOT / "data" / "example" / "機械学習用データセット.xlsx"

# 2. 読み込む学習済みモデル (.joblib)
DEFAULT_MODEL_FILE = PROJECT_ROOT / "models" / "trained" / "best_model_classification_GradientBoosting.joblib"

# 3. 予測結果の出力Excelファイルパス
DEFAULT_OUTPUT_EXCEL = PROJECT_ROOT / "reports" / "validation" / "prediction_results.xlsx"

# ==========================================================
```

## 4. 主な機能と特徴

- **自動タスク種別判定**:
  モデルファイル内のメタデータから分類タスクか回帰タスクかを自動識別し、最適な推論処理および出力列（確率スコア / 連続予測値）を構成します。
- **データクレンジングと欠損行の安全処理**:
  特徴量に含まれる欠損値（NaN）や無限大値（Inf）を自動検出し、無効な行を安全にスキップして正常行のみを推論対象にします。
- **洗練されたExcelスタイル適用**:
  出力される Excel レポートには、見やすいヘッダー装飾、テーブルスタイル指定、自動列幅調整、数値フォーマット（小数点以下桁数の統一）が自動適用されます。

---

## 5. 実行方法

### 基本実行（スクリプト内設定エリアに従う）
```bash
# 引数なしで実行
python scripts/validate/predict_ml_models.py
```

### オプション指定実行（コマンドラインから指定する場合）
```bash
python scripts/validate/predict_ml_models.py \
  --input "data/example/新規測定データ.xlsx" \
  --model "models/trained/best_model_regression_Lasso.joblib" \
  --output "reports/validation/新規データ予測結果.xlsx"
```

---

## 6. 注意点・トラブルシューティング

1. **特徴量カラムの不足エラー**:
   - 入力データに学習時と同じ特徴量列（例: `2-8`, `4-10/2-8` 等）が存在しない場合、エラーメッセージが表示されます。必ず `build_ml_dataset.py` を通して生成されたデータセットを使用してください。
2. **モデルファイルの読み込みエラー**:
   - scikit-learn のバージョン差異により警告が出力される場合がありますが、`train_ml_models.py` で保存された `.joblib` ファイルであれば正常に推論が完了します。
